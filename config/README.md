# 运行时配置（非密钥）

v2.5 起 wengu 内核**零模型**，模型档位、供应商路由等参数已退役。本目录只放
**非密钥运行时参数**，每次请求现读、改文件即生效（热加载），无需重启。

- 密钥（如将来接入本地模型）仍只放 `wengu-api/.env`，绝不进本目录。
- `app-config.json` 已被 `.gitignore` 忽略（本机配置）；需要时复制
  `app-config.example.json` 为 `app-config.json`，缺失则使用内置默认值。
- 可用环境变量 `WENGU_APP_CONFIG` 指向其他路径（测试用）。

| 键 | 默认 | 说明 |
|---|---|---|
| `daily_review_limit` | `10` | 每日到期复习上限（1–200）：超过上限的到期项不显示、只计数，顺延到后续复习日，不丢失、不惩罚 |
| `exam_day_limit_factor` | `1.5` | 日历上今天有 `kind='exam'` 事件时的上限放大系数（≥1）：`min(round(上限 × 系数), 200)`；缺失/非法/小于 1 回退默认；竞赛/请假/其它事件不放宽 |

> 课表/日历本身只是约束层：课表不参与选题、排序或冲突检测，也不从课表生成任务。
